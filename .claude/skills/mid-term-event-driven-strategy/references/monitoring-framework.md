## 监控核心原则

> **持有期间，需每日对核心逻辑进行跟踪，而不是盯着分时图。**

事件驱动策略的收益不来自日内波动，而来自催化剂发酵过程中的重估。分时图的涨跌是噪声；催化剂跟踪表中的"绿灯"/"红灯"才是信号。

## 催化剂跟踪表

对每个持仓标的建立以下跟踪表，每日更新。

### 跟踪维度

| 监控维度 | 数据来源 | 更新频率 |
|:--|:--|:--|
| 事件进度 | 公司公告、交易所披露 | 每日检查 |
| 产业链数据 | 行业数据（出货量/价格/资本开支） | 每周更新 |
| 公司公告 | 公司公告（定期报告/临时公告） | 每日检查 |

## 危险信号详解

### 🟢 及格状态 vs 🔴 危险信号

| 监控维度 | 🟢 及格状态 | 🟡 关注信号 | 🔴 危险信号 |
|:--|:--|:--|:--|
| **事件进度** | 按公告/计划节点推进 | 节点延迟1-2周，有合理解释 | **任意节点延迟超过2周且无合理解释** |
| **产业链数据** | 上下游数据持续向好 | 数据增速放缓但绝对值仍好 | **行业龙头突然下调指引** |
| **公司公告** | 定期报告无负面偏差 | 非核心指标小幅低于预期 | **突发非经常性损益预警** |
| **技术量价** | 缩量回调不破关键均线 | 连续缩量阴跌但未破120日线 | **放量跌停或连续2日跌破120日线** |
| **市场预期** | 新研报开始覆盖并上调 | 覆盖迅速增加，预期趋于一致 | **预期迅速过度一致 + 股价钝化** |

### 危险信号的响应机制

| 危险信号 | 首次出现时的动作 | 持续时 |
|:--|:--|:--|
| 🔴 节点延迟 > 2周 | 立即减仓 30%，联系公司IR/查公告 | 若再1周无进展 → 清仓 |
| 🔴 龙头下调指引 | 减仓 50%，重新评估行业景气度 | 若同行业第2家公司也下调 → 清仓 |
| 🔴 非经常性损益预警 | 立即减仓 50%，核实是否影响主营业务 | 若主营业务也受影响 → 清仓 |
| 🔴 放量跌停/破120日线 | 次日开盘清仓 | — |
| 🔴 预期过度一致 + 钝化 | 减仓 50% | 进入止盈观察模式 |

## 逻辑失效判定

### 核心催化剂否定 → 无条件清仓

一旦核心催化剂被直接否定，触发"逻辑止损"，无条件清仓：

| 催化剂类型 | 逻辑失效判定 |
|:--|:--|
| 业绩超预期 | 业绩预告大幅下修；实际EPS不及预期且低于上年同期 |
| 产业景气验证 | 上游资本开支指引下调 > 10%；行业出货量环比下降 |
| 并购与资产重组 | 重组终止、撤回申请、被证监会否决 |
| 困境反转 | ST重新戴帽；原黑天鹅事件出现新进展导致基本面恶化 |
| 政策与监管 | 利好政策被撤销；出台行业利空政策直接打击 |

### 半失效信号（重新评估但不一定清仓）

| 信号 | 动作 |
|:--|:--|
| 催化剂延期但新时间表已公告 | 重新评估时间止损起始点 |
| 行业景气度不变但个股跑输行业 | 检查个股特有风险 |
| 技术面转弱但催化剂仍在推进 | 以催化剂为主，但收紧止损至 -5% |

## 每日复盘流程

每交易日收盘后，按此流程更新：

### 第1步：事件进度检查（5分钟）

- [ ] 查看公司最新公告（巨潮资讯网/东方财富）
- [ ] 确认催化剂所在节点是否按计划推进
- [ ] 有任何延迟，记录延迟原因和预计新时间

### 第2步：量价检查（3分钟）

- [ ] 收盘价是否跌破关键均线？
- [ ] 成交量是否异常？（放量跌/极度缩量）
- [ ] 是否有"射击之星"等见顶形态？

### 第3步：浮盈亏检查（1分钟）

- [ ] 浮亏是否逼近 -8% 止损线？
- [ ] 浮盈是否触及 +20% 止盈线（且尚未减半）？
- [ ] 建仓是否已满 8 周？

### 第4步：信号判断（2分钟）

- [ ] 跟踪表所有维度是否绿灯？→ 持有
- [ ] 是否有黄灯？→ 密切关注，收紧条件
- [ ] 是否有红灯？→ 立即执行对应操作

### 第5步：决策记录（2分钟）

无论是否操作，记录当日决策和原因：
```
日期：________
持仓状态：持有 / 减仓 / 加仓 / 清仓
操作：（如有）买入/卖出 ____ 股，价格 ____
原因：________
下次关注节点：________
```

## 每周深度复盘

每周末进行一次深度复盘，检查日频数据之外的周频/低频指标。

### 周度检查清单

| 检查项 | 数据来源 | 关注点 |
|:--|:--|:--|
| 北向资金周净流入/流出 | `stock_data.py --northbound` | 外资对该行业/个股的态度变化 |
| 融资余额变化 | 东方财富融资融券数据 | 杠杆资金方向 |
| 行业指数相对强弱 | 行情数据 | 该标的所属行业 vs 沪深300的周度表现 |
| 分析师报告更新 | 东方财富研报 | 新增覆盖或评级调整 |
| 大宗交易 | 交易所大宗交易数据 | 是否有大资金进出 |
| 板块轮动 | 行业板块实时数据 | 主线是否切换？该板块成交占比是否下降？ |

### 周度反思问题

1. 催化剂逻辑与上周相比有什么变化？（强化/不变/弱化）
2. 有没有出现新的、本策略未覆盖的风险因素？
3. 大盘环境是否发生了质变？（趋势/波动率/情绪）
4. 仓位参数是否仍在纪律范围内？
5. 是否有更好的催化剂机会出现？（机会成本评估）
