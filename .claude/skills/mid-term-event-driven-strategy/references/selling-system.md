## 卖出机制总览

| 优先级 | 卖出类型 | 触发条件 | 操作 |
|:--|:--|:--|:--|
| 1（最高） | **硬性止损** | 浮亏达 -8% | 立即无条件清仓 |
| 2 | **逻辑止损** | 催化剂本身流产 | 立即无条件卖出（即使亏损未到 -8%） |
| 3 | **时间止损** | 建仓满8周无进展 | 减仓50%；再2周仍无动静则清仓 |
| 4 | **主动止盈** | 浮盈 +20%~25% 或 催化剂落地 | 分批卖出 |

## 第一类：主动止盈（分批）

### 第一止盈点：利润保护

| 项目 | 内容 |
|:--|:--|
| **触发条件** | 浮盈达 +20% ~ +25% |
| **操作** | 卖出持有股数的 **50%** |
| **效果** | 剩余持有成本大幅摊低，后续心态更稳 |
| **后续** | 剩余50%持有至最终清仓条件触发 |

**为什么是 50% 而不是全卖？**
- 催化剂可能尚未完全兑现（主升浪才到中途）
- 卖出50%后成本极低甚至为负，可以冷静持有剩余仓位
- 如果后续下跌，利润已锁；如果继续上涨，仍有参与

### 最终清仓点

满足**任一项**即全部卖出：

| # | 条件 | 判断标准 |
|:--|:--|:--|
| A | 催化剂事件正式落地 | 催化剂公告已发布（财报、重组完成、政策细则出台等） |
| | + 市场剧烈反应 | 近3个交易日连续大涨 |
| | 执行时机 | 于消息后第 3–5 个交易日分批清仓 |
| B | 高位放量长上影线 | "射击之星"形态（上影线 > 实体 2倍） |
| | + 高换手 | 当日换手率 > 20% |
| | 执行时机 | 次日开盘清仓 |
| C | 跌破10日均线 | 收盘价跌破10日均线 |
| | + 3日内无法收回 | 此后3个交易日收盘均未站回10日线 |
| | 执行时机 | 第3日收盘确认后次日清仓 |
| D | 一致预期过度乐观 | 分析师覆盖迅速增加 + 目标价集中大幅上修 |
| | + 走势钝化 | 利好公告后股价不再上涨（"利好出尽"） |
| | 执行时机 | 观察确认后分批清仓 |

### 分批清仓时间表

适用于条件 A（催化剂落地后分批清仓）：

| 批次 | 时间 | 比例 |
|:--|:--|:--|
| 第1批 | 消息后第3个交易日 | 剩余仓位的 34%（即总剩余约1/3） |
| 第2批 | 消息后第4个交易日 | 剩余仓位的 33% |
| 第3批 | 消息后第5个交易日 | 全部剩余 |

## 第二类：硬性止损

### 规则

> **浮亏达到 -8%，无论任何理由，立即清仓离场。这是铁律，不接受回撤扩大。**

| 项目 | 内容 |
|:--|:--|
| **触发线** | 持仓浮亏 = **-8%**（以加权平均成本计算） |
| **操作** | 立即无条件清仓（全部卖出） |
| **不接受的理由** | 任何理由都不接受——"马上就反弹了"、"基本面很好"、"大盘不好"、"催化剂快到了"——都不允许 |
| **清仓后纪律** | 清仓后至少等待 3 个交易日，冷静复盘，方可重新评估该标的 |

### 为什么是 -8%？

- -8% 是策略的"纠错成本"。超过这个亏损，说明要么催化剂判断错了，要么建仓时机错了
- 回撤控制是长期盈利的基础：一次 -8% 止损需要约 +8.7% 收回，可控
- 一次 -20% 需要 +25% 收回，一次 -50% 需要 +100% 收回——回撤越大，收回越难

### 止损执行要点

1. **到达即执行，不等收盘**：盘中触及 -8% 立即挂单，不等到收盘确认
2. **不使用止损单**（A股不支持止损单），但心理上必须做到
3. **卖出后不要立即回头看**：卖出后至少3天不关注该标的，避免情绪化反手交易

## 第三类：逻辑止损

### 规则

> **催化剂本身出现明确"流产"信号，即使亏损未到 -8%，也必须立即无条件下跌中卖出。不可存幻想。**

### 触发条件

| # | 流产信号 | 判断标准 |
|:--|:--|:--|
| 1 | 订单/合同取消 | 公司公告订单取消或终止 |
| 2 | 重组/并购终止 | 公告重组终止、撤回申请、被否决 |
| 3 | 业绩预告大幅下修 | 业绩预告从预盈→预亏，或增速从 +30% → -10% |
| 4 | 政策转向 | 原有利好政策被撤销或出台利空政策 |
| 5 | 关键客户流失 | 公告失去重大客户（营收占比 > 20%） |
| 6 | 财务暴雷 | 突发的财务造假指控、监管立案调查公告 |
| 7 | 行业龙头崩塌 | 行业龙头公司破产/退市风险，信号传导至全行业 |

### 执行

- **立即卖出**：公告发布后第一时间卖出，不等待"反弹"
- 如果跌停无法卖出，次日继续挂单
- 逻辑止损的卖出价格不以成本为参照——即使亏损已超 -8%，也不犹豫

### 逻辑止损 vs 硬性止损的区别

| | 硬性止损 | 逻辑止损 |
|:--|:--|:--|
| 触发原因 | 价格亏损 | 催化剂逻辑破灭 |
| 触发价位 | -8% | 任何价位 |
| 决策依据 | 价格纪律 | 催化剂跟踪 |
| 执行紧迫度 | 高 | 最高 |

## 第四类：时间止损

### 规则

> **建仓后持有满 8 周，股价仍然在成本价 ±3% 区间内窄幅震荡，且无明显正向催化剂进展，触发时间止损。**

### 触发条件（需同时满足）

| # | 条件 | 标准 |
|:--|:--|:--|
| 1 | 时间 | 建仓之日起已满 8 周 |
| 2 | 价格 | 股价在成本价 ±3% 区间内震荡（无趋势） |
| 3 | 催化剂 | 无明显的正向催化剂进展（无新公告、无数据改善） |

### 执行

| 阶段 | 操作 |
|:--|:--|
| 满 8 周触发 | 减仓 **50%**，回收资金 |
| 减仓后观察 2 周 | 若仍无动静，清仓剩余 50% |
| 减仓后催化剂出现 | 可重新评估是否接回或保持剩余仓位 |

### 逻辑

资金的时间成本是隐性风险。8周的等待期已经足够让一个有价值的催化剂产生进展信号。如果8周过去了仍然没有动静，说明：
- 催化剂可能比预期的更远（时间误判）
- 或者催化剂不够强（市场不认可）
- 或者根本就是伪催化剂

此时，即使不亏钱，也应该回收资金去寻找更好的机会。

    │       否
    │       │

## 卖出执行原则

1. **卖得快比卖得巧重要**：到达卖出条件就执行，不试图"卖在最高点"
2. **分批优于一次性**：止盈时分批卖出，减少"卖飞"的心理遗憾
3. **清仓后不看**：无论盈还是亏，清仓后至少3天不关注该标的
4. **卖出后复盘**：每次卖出后记录：
   - 卖出原因（哪种触发条件）
   - 实际收益率（年化）
   - 催化剂最终结果（完全兑现/部分兑现/流产）
   - 经验教训
5. **不在恐慌中卖出**：如果触发卖出的原因是"别的股票都在跌，我也害怕"——这不是任何一类的触发条件。检查跟踪表，逻辑没坏就持有。
