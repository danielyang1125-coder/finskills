## 风控体系总览

```
第六层：极端行情 ─── 全市场跌停 > 20家 → 暂停一切交易
    ↑
第五层：利润保护 ─── 收益+20%降至50%仓，+50%降至30%
    ↑
第四层：流动性 ─── 日均成交额 ≥ 5000万元
    ↑
第三层：账户月 ─── 月回撤 > 10% → 当月清仓休息
    ↑
第二层：账户日 ─── 日亏损 > 2% → 当日停止新开仓
    ↑
第一层：单票 ─── 硬止损 -8%
```

## 第一层：单票层面

### 硬止损

| 参数 | 值 |
|:--|:--|
| 止损线 | **-8%**（以加权平均成本计算） |
| 执行 | 无条件立即清仓 |
| 纪律 | 不接受任何理由的例外 |

详见 [selling-system.md](selling-system.md) 第二类卖出。

### 单票上限

| 参数 | 值 |
|:--|:--|
| 单票计划仓位 | ≤ 50% 可投资金 |
| 同时运行标的 | ≤ 2 只（不同细分方向） |
| 总持仓上限（初始） | ≤ 60% 可投资金 |

## 第二层：账户日风控

### 规则

> **若单日账户总权益亏损触及 2%，当日停止所有新开仓。**

| 参数 | 值 |
|:--|:--|
| 触发线 | 日亏损 = 2% 账户权益 |
| 计算基准 | 当日开盘前账户总权益 |
| 操作 | 当日不再开任何新仓位（已持仓位按原计划管理） |
| 恢复 | 次日自动恢复，但需复盘亏损原因后再操作 |

### 为什么是 2%？

- 单日亏损 2% 通常意味着市场出现了未预期的负面冲击
- 此时新开仓的胜率因情绪偏差而大幅降低
- 给大脑一个"冷却期"，避免情绪化连续交易

---

## 第三层：账户月风控

### 规则

> **月度最大回撤达 10%，当月清仓所有持仓，强制休息至月末。**

| 参数 | 值 |
|:--|:--|
| 触发线 | 月度回撤 = 10% |
| 计算方式 | 当月最高权益 → 当前权益的降幅 |
| 操作 | 清仓所有持仓，当月不再开新仓 |
| 恢复 | 次月首个交易日恢复，重新评估市场环境 |

### 为什么是 10%？

- 月回撤 10% 意味着策略或市场环境出现了系统性问题
- 连续交易亏损时有"翻本"心理，强制空仓打破恶性循环
- 用时间换空间，让市场情绪和自身心理都重置

---

## 第四层：流动性风控

### 规则

| 参数 | 值 |
|:--|:--|
| 最低日均成交额 | ≥ **5000 万元** |
| 不参与的标的 | 日均成交额 < 5000 万元的标的（流动性不足） |

### 为什么是 5000 万？

- 如果以可投资金的最小假设，5000万日均成交额可保证单个投资者（百万级别资金）的进出不造成显著冲击
- 日均成交额 < 5000万的标的，即使判断正确，也可能因流动性不足无法及时离场

### 流动性检查

- 建仓前：检查近20日日均成交额
- 持仓期：每日检查日均成交额是否萎缩
- 如果持仓期间日均成交额萎缩至 < 3000万 → 择机减仓

---

## 第五层：利润保护机制

### 金字塔降仓规则

> **账户总收益越高，总仓位上限越低。赚到的钱先锁住。**

| 收益阶段 | 总仓位上限 | 说明 |
|:--|:--|:--|
| 初始 | 60% | 正常操作区间 |
| 浮盈 +10% | 60% | 保持，但密切关注 |
| 浮盈 +20% | **50%** | 自动下调，若超出则减仓至50% |
| 浮盈 +30% | **40%** | 继续锁利 |
| 浮盈 +50% | **30%** | 极度保守 |

### 降仓执行

- 达到降仓线时，优先减仓浮盈最大的标的
- 如果只有一个标的且仓位 > 新上限，减仓至新上限
- 降仓的卖出不需要等待其他卖出信号

## 第六层：极端行情应对

### 避险模式触发条件

| 条件 | 操作 |
|:--|:--|
| 全市场跌停家数 > 20 家 | 暂停一切交易，仅持有现金 |
| 沪深300单日跌幅 > 5% | 现有持仓收紧止损至 -5% |
| 连续3日全市场上涨家数 < 500 | 不新开仓，考虑减仓 |
| 恐慌指数（IV）单日飙升 > 50% | 暂停新开仓，收紧止损 |

### 避险期间规则

1. 不新开任何仓位
2. 已持标的的止损线收紧至 -5%
3. 每日只做观察，不做交易
4. 恢复条件：全市场跌停家数降至 < 5 家且沪深300连续2日收阳

## 风控检查清单

### 开盘前检查

- [ ] 账户总权益 → 计算当日 2% 亏损线 = 权益 × 0.02
- [ ] 持仓浮亏监测 → 是否有逼近 -8% 的标的？
- [ ] 月回撤监测 → 本月是否已接近 10% 红线？
- [ ] 仓位检查 → 总仓位是否在允许范围内？
- [ ] 市场环境 → 全市场跌停家数？是否有极端行情？

### 盘中提醒（可由AI触发）

- ⚠️ 持仓浮亏触及 -6%：准备止损，距 -8% 仅差 2%
- ⚠️ 日亏损触及 -1.5%：距日熔断仅差 0.5%
- ⚠️ 全市场跌停 > 10 家：关注是否触发避险模式

### 收盘后检查

- [ ] 更新各持仓的催化剂跟踪表（参见 monitoring-framework.md）
- [ ] 检查是否有触发的卖出信号
- [ ] 计算当日盈亏和累计收益
- [ ] 更新仓位上限（如果收益达到新的锁利阶梯）
- [ ] 记录当日所有操作和原因
