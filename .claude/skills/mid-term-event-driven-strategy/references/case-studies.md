## 标准成功案例：中际旭创（2025-2026）

### 催化剂信息

| 项目 | 内容 |
|:--|:--|
| 催化剂类型 | 业绩超预期 + 产业景气验证（双驱动） |
| 核心催化 | 全球AI军备竞赛 → 高速光模块需求爆发 → 业绩持续超预期 |
| 行业 | 光通信 / AI算力基础设施 |

### 时间线与策略嵌入点

#### 2025年Q1-Q2：漏斗一通过

| 事件 | 策略对应 |
|:--|:--|
| 北美云厂商资本开支指引上修 | 漏斗一：产业全球共振确认 |
| 光通信板块成交额占比持续 > 10% | 漏斗一：主线确认 |
| 美股光通信板块走强（相干/光模块） | 漏斗一：美股共振向上 |

**策略状态**：光通信板块进入主线视野，纳入漏斗一候选池。

#### 2025年7月：漏斗二+漏斗三 → 建仓触发

| 事件 | 策略对应 |
|:--|:--|
| 市场预期Q2业绩高增，但具体有多高存在分歧 | 漏斗二：市场认知度中等（有分歧 = 有预期差） |
| 业绩预告在前2-4周窗口 | 漏斗二：时间临近度评分高 |
| 股价回调至60日均线附近获得支撑 | 漏斗三：均线支撑确认 |
| 出现底部倍量阳线 | 漏斗三：量价形态确认 |
| 流通市值在30-100亿区间 | 漏斗三：市值范围符合 |

**催化剂评分**（回顾性）：
- 事件确定性：大概率（25/30）
- 业绩弹性：净利润可能翻倍以上（30/30）
- 市场认知度：已有5家覆盖但分歧大（15/20）
- 时间临近度：4周内（15/20）
- **总分：85** ✅

**策略动作**：首仓40%计划资金，在60日均线附近分2笔买入。

#### 2025年8月：加仓信号触发

| 事件 | 策略对应 |
|:--|:--|
| 半年报公布：营收增60%，净利增108%，大幅超普遍预期的50% | 加仓信号A：催化剂先导信息公布 |
| 公告后高开约4%，盘中回落至均线 | 价格条件满足（高开 ≤ 5%） |

**策略动作**：追加30%仓位，总仓位达到70%计划资金（但未超单票50%总资金上限）。

#### 2025年Q3 – 2026年Q1：持仓跟踪期

每个财报节点均超预期，催化剂跟踪表持续绿灯：

| 监控维度 | 状态 |
|:--|:--|
| 事件进度 | 🟢 每个财报季如期公布，持续超预期 |
| 产业链数据 | 🟢 北美CSP资本开支持续上修，光模块出货量环比增长 |
| 公司公告 | 🟢 无负面偏差 |
| 技术量价 | 🟢 缩量回调不破60日线 |
| 市场预期 | 🟢→🟡 分析师覆盖从5家增至15+，预期趋于一致 |

#### 卖出触发

| 时机 | 卖出类型 | 操作 |
|:--|:--|:--|
| 2025年Q3-Q4间（多次） | 主动止盈第一点 | 浮盈每次触及+20-25%，卖出50%锁利 |
| 2026年Q1后期 | 主动止盈最终 | 营收增速斜率放缓 + 市场一致性极度乐观 + 高位放量震荡 → 分批清仓 |

### 策略收益路径（不涉及具体金额）

建仓 → 首笔浮盈25%减半（成本大幅摊低） → 剩余仓位持有至主升浪末尾 → 多次分批锁利 → 总收益可超过100%。

### 关键教训

1. **双驱动催化剂**（业绩超预期 + 产业景气验证）的强度和持续性远超单一驱动
2. **每季财报都是新的加仓/检验窗口**，不是一次性事件
3. **"卖一半"策略**让投资者在主升浪中既能锁利又能保持参与
4. **预期趋于一致时**是最危险的时候，即使基本面还在变好

## 典型失败案例：海南华铁算力订单流产（2025）

### 催化剂信息

| 项目 | 内容 |
|:--|:--|
| 催化剂类型 | 并购与资产重组（跨界算力大单） |
| 核心问题 | 催化剂停留在"框架协议"阶段 |
| 失败核心 | 低确定性 → 伪催化剂 |

### 失败路径分析

#### 漏斗二：应被淘汰

| 必答题 | 当时回答 | 按策略应判 |
|:--|:--|:--|
| 催化剂是什么？ | 签署了"合作协议"，欲跨界算力 | — |
| 时间窗口？ | 不明确 | ❌ 模糊，应淘汰 |
| 已被广泛预期？ | 消息刺激一字板 | — |
| 能量化吗？ | 无法——无定金、无采购名单、无时间节点 | ❌ 无法量化 |
| 来源是正式公告？ | 框架协议公告 | ⚠️ 仅框架 |

**催化剂强度评分**（回顾性）：
- 事件确定性：仅框架协议（10/30）
- 业绩弹性：无法估算（0/30）
- 市场认知度：一字板后广泛关注（5/20）
- 时间临近度：无明确时间（5/20）
- **总分：20** ❌ — 远低于70分的通过线

**策略判决**：应直接淘汰于漏斗二。

#### 持仓跟踪：持续红灯

| 时间 | 事件 | 跟踪表信号 |
|:--|:--|:--|
| 公告时 | 签署框架合作协议 | 🟡 低确定性，仅观察 |
| 公告后1个月 | 无任何进展信息 | 🟡 事件进度无进展 |
| 公告后3个月 | 仍无进展，无采购公告 | 🔴 事件进度停滞 |
| 公告后6个月 | 公告协议取消 | 🔴 催化剂流产 |

**策略判决**：公告后1-3个月间的"事件进度停滞"持续红灯，应在取消公告前就触发逻辑止损。

#### 买入点错误

| 问题 | 策略规则违反 |
|:--|:--|
| 消息后直接一字板，无法在左侧建仓 | 违反"建仓必须在消息传开前偏左侧" |
| 若开板追高买入 | 违反"不加仓涨幅已大"规则 |

### 教训

**只做有实质性进展且可跟踪验证的事件，远离纯讲故事的"伪催化剂"。**

| 策略规则 | 本案例 |
|:--|:--|
| 催化剂必须可量化 | 框架协议无任何量化内容 → 不参与 |
| 只参与有实质公告的项目 | 仅框架协议 → 不参与 |
| 节点延迟是危险信号 | 持续无进展 → 应触发逻辑止损 |
| 不追一字板 | 无左侧建仓机会 → 放弃 |

## 成功案例：某算力芯片公司并购（2024-2025）

### 催化剂信息

| 项目 | 内容 |
|:--|:--|
| 催化剂类型 | 并购与资产重组 |
| 核心催化 | 收购AI芯片新锐，产业协同清晰 |
| 结果 | 股价涨近9倍 |

### 策略框架对应

| 阶段 | 事件 | 策略动作 |
|:--|:--|:--|
| 公告前 | 市场有并购传闻但未被充分重视 | 漏斗二：认知度低 → 加分 |
| 公告日 | 发布正式收购方案（确定性高） | 漏斗二：确定性30/30 |
| 公告后 | 方案细节：合理对价 + 业绩承诺 + 产业协同 | 漏斗二：能量化弹性 |
| 审批期 | 各节点如期推进 | 监控：跟踪表持续绿灯 |
| 实施完成 | 并购完成，协同效应开始兑现 | 卖出：催化剂落地，分批止盈 |

### 与失败案例的关键对比

| 维度 | 本案例（成功） | 海华铁（失败） |
|:--|:--|:--|
| 公告性质 | 正式收购方案 | 框架合作协议 |
| 确定性 | 高（有对价、有业绩承诺） | 低（无细节） |
| 时间线 | 明确（审批节点清晰） | 模糊 |
| 可量化性 | 高（标的利润可估算） | 无 |
| 漏斗二评分 | ≥ 80 | ≈ 20 |

## 失败案例：伪催化剂之CEO互动平台自夸

### 描述

某公司CEO在互动平台自问自答，夸大芯片研发进度。后被证监会立案调查并处罚，股价打回原形。

### 策略规避

| 伪催化剂特征 | 本案例 | 策略判决 |
|:--|:--|:--|
| 概念模糊 | "芯片研发取得重大突破"（无具体产品） | ❌ 淘汰 |
| 无营收支撑 | 无芯片相关营收 | ❌ 淘汰 |
| 无订单/产能 | 无任何量产计划 | ❌ 淘汰 |
| 无时间路线图 | "未来将..." | ❌ 淘汰 |
| 管理层自说自话 | 来自互动平台，非正式公告 | ❌ 淘汰 |

**漏斗二必答题第5问**（消息是否来自正式公告？）直接淘汰。

## 案例教训总结

### 成功案例的共同特征

1. **催化剂可量化**：能用具体指标描述（"净利润同比增长100%"、"收购对价XX亿"）
2. **时间窗口明确**：知道催化剂何时落地（财报日期、审批节点）
3. **来源正式**：来自正式公告/财报/监管文件，非传闻或互动平台
4. **认知度低**：在催化剂发酵初期，市场关注度不高
5. **双驱动加分**：多个催化剂类型同时共振时，胜率和赔率都大幅提升

### 失败案例的共同特征

1. **概念模糊**：无法用具体指标描述催化剂
2. **缺乏细节**：框架协议、意向书、口头承诺而无实质内容
3. **时间未知**：不知道催化剂何时落地
4. **已被充分定价**：利好出来时股价已涨到位
5. **来源不可靠**：互动平台、媒体猜测、小道消息

### 策略的最优适应场景

| 催化剂组合 | 历史胜率 | 说明 |
|:--|:--|:--|
| 业绩超预期 + 产业景气验证 | 最高 | 双驱动相互验证 |
| 产业景气验证单独 | 高 | 但需要耐心等待业绩兑现 |
| 并购重组（高确定性） | 中高 | 需严格跟踪审批节点 |
| 困境反转 | 中 | 需要极强的行业知识判断"真的反转" |
| 政策驱动 | 中低 | 受政策变化影响大，持续性不确定 |
| 低确定性重组/伪催化剂 | 极低 | 不应参与 |
