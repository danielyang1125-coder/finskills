## 3.1 业绩超预期驱动

### 描述

公司财报公布的收入/利润/订单增速显著超越市场一致性预期。

### 识别条件

**必须同时满足**：
1. 最新季报实际 EPS 超过券商一致预期 ≥ 10%，或营收超预期 ≥ 5%
2. 扣非净利润率为正且趋势向好（环比改善或同比改善）
3. 超预期的驱动因素具有持续性（非一次性非经常性损益）

### 关键跟踪指标

| 指标 | 数据来源 | 评判标准 |
|:--|:--|:--|
| 季度营收同比增速 | 财报 + 一致预期 | 实际 vs 预期差值 > 5% |
| 扣非净利润率变化 | 财报 | 环比/同比改善 |
| 新增订单/预收账款 | 资产负债表附注 | 环比增长 > 10% |
| 合同负债变化 | 资产负债表 | 环比增长 > 10%（预示未来收入） |
| 毛利率变化 | 利润表 | 连续两季改善（排除价格战嫌疑） |
| 经营现金流/净利润 | 现金流量表 | > 0.8（盈利质量确认） |

### 常见陷阱

- **一次性收益**：出售资产、政府补贴等非经常性损益不能算作"超预期"
- **基数效应**：去年同期极低基数导致的"高增长"需打折评估
- **符合预期 = 利好兑现**：只有明显超越预期差才能驱动股价，符合预期常导致下跌

### 案例框架

某算力光模块公司，2025年全年净利润同比增长108%，2026年Q1继续增长262%，股价在业绩公布后继续攀升，全年涨幅约400%。

## 3.2 产业景气度验证驱动

### 描述

全球/国内领军企业资本开支、出货量、技术路线确认，带来产业链上下游从"概念"进入"业绩兑现"阶段。

### 识别信号（满足任一项即可进入观察）

| 信号类型 | 具体指标 | 阈值 |
|:--|:--|:--|
| 上游资本开支 | 科技巨头（北美CSP等）资本开支指引大幅上修 | 上修幅度 > 15% |
| 关键基础设施出货 | 液冷、HBM存储、高速光模块等出货量 | 连续两季环比增长 > 20% |
| 下游订单追加 | 产业链公司公告获得追加订单 | 订单金额 > 上年营收的10% |
| 产能扩张 | 核心公司宣布扩产计划 | 扩产规模 > 现有产能的30% |

### 产业链传导逻辑

```
上游巨头发布资本开支数据 → 中游设备/零部件迎来采购需求
    ↓
供应商获得订单（公告） → 催化剂已可量化
    ↓
中游公司季报开始兑现业绩 → 市场学习充分，进入主升浪
```

操作要点：需提前锁定产业链内对标的。当上游巨头发布资本开支数据时，可视作中游标的的催化剂"上游先行信号"。

### 案例框架

2025-2026年全球AI算力投资爆发，北美云厂商资本开支指引连续上修，带动光通信、液冷、HBM三大细分赛道业绩全面兑现，相关公司股价中枢大幅上移。

## 3.3 并购与资产重组驱动

### 描述

公司被收购、注入优质资产、控制权变更，导致价值重估。

### 催化剂确定性等级

| 等级 | 定义 | 是否可操作 |
|:--|:--|:--|
| **高确定性** | 已公告具体方案、有约束力框架协议、已支付定金 | ✅ 可操作 |
| **中确定性** | 签署意向协议，但缺乏细节（对价、时间表） | ⚠️ 需密切关注进展 |
| **低/伪催化剂** | 仅"筹划"、"传闻"，无实质内容 | ❌ 不可操作 |

**核心纪律**：仅参与已有实质性公告且后续每个节点都如期推进的项目。任何节点延迟都当做危险信号。

### 跟踪节点清单

| 节点 | 预期时间 | 关注点 |
|:--|:--|:--|
| 停牌/筹划公告 | - | 标的初步确定 |
| 董事会预案 | 公告后1-2周 | 交易方案细节（对价、支付方式、业绩承诺） |
| 股东大会审议 | 公告后1-2个月 | 中小股东反对风险 |
| 证监会/交易所受理 | 提交后1-3个月 | 材料是否补正 |
| 审核（如需） | 受理后2-6个月 | 否决风险 |
| 注册/核准 | 审核通过后1个月 | 一般能通过 |
| 实施完成 | 批准后1-3个月 | 执行风险 |

### 案例框架（成功与失败对比）

- **成功**：某算力芯片公司宣布收购某AI芯片新锐，股价涨近9倍（确定性高+业绩承诺实在+产业逻辑清晰）
- **失败**：某公司公告36.9亿元大单框架协议，但半年无进展，最终取消，公告次日一字跌停（仅框架协议，无定金/无采购名单/无时间节点）

## 3.4 困境反转驱动

### 描述

ST摘帽、财务造假风波落定、行业衰退结束后龙头业绩拐点确认。

### 识别条件（需同时满足至少3项）

| 条件 | 具体标准 |
|:--|:--|
| 财务连续改善 | 毛利率、经营现金流、应收账款周转率连续两季改善 |
| 黑天鹅了结 | "黑天鹅"事件已彻底了结（处罚落地、诉讼终结、监管结案） |
| 行业同步信号 | 同行业多家公司出现同步改善信号（排除个股操纵） |
| 月度价格反转 | 股价在长期月线低位盘整，突然放量突破120日均线 |
| 基本面公告确认 | 出现基本面改善的正式公告（摘帽申请、业绩预盈、大额订单） |

### 买点特征

- 股价处于长期月线低位（距历史高点跌幅 > 60%）
- 在低位盘整 > 3个月
- 突然放量突破120日均线（量能 > 50日均量的200%）
- 同时出现基本面改善的正式公告

### 案例框架

某网游公司因财务造假被ST，股价从3元附近涨至20元以上。催化剂链条：处罚落地（黑天鹅了结）+ 新业务起量（基本面改善）+ 摘帽预期。

## 3.5 政策与监管驱动

### 描述

国家级产业政策、法规出台或重大监管规则变化，带来板块性估值重塑。

### 有效政策特征（必须满足全部）

| 特征 | 说明 |
|:--|:--|
| **可执行性** | 有具体行动计划、资金支持额度、税收优惠条款，非空洞口号 |
| **直接受益** | 产业链直接受益而非间接关联（能指向具体A股公司） |
| **增量逻辑** | 政策力度超越已有市场预期（不是"老生常谈"） |

### 操作规则

1. **不追高**：政策公布后通常带动板块集体高开，不可追涨
2. **等冷却**：等待首次热度冷却（约3-5天）
3. **选纯正**：挑选基本面最纯正的标的（该业务在营收中占比 > 30%）
4. **等回调**：在股价回调至关键均线（60日或120日）时建仓

### 政策有效性衰减信号

- 政策文件发布后2周内无配套实施细则出台
- 受益板块成交额迅速萎缩（热度 < 首日的30%）
- 多部门政策互相矛盾或执行节奏不协调

## 催化剂强度评分表

基于四维度加权评分，总分100。通过线：**≥ 70**。

| 因子 | 权重 | 满分标准 | 打分指引 |
|:--|:--|:--|:--|
| **事件确定性** | 30% | 已公告具体方案/已获审批/已支付定金 | 30分=已确定；20分=极大概率；10分=可能；0分=传闻 |
| **业绩弹性** | 30% | 可带来30%以上净利润增长 | 30分=>30%弹性；20分=15-30%；10分=5-15%；0分=<5%或无量化 |
| **市场认知度** | 20% | 关注度极低、无分析师覆盖或仅1-2家覆盖 | 20分=无覆盖；15分=1-2家；10分=3-5家；5分=>5家广泛覆盖 |
| **时间临近度** | 20% | 催化剂在2-4周内落地 | 20分=2周内；15分=2-4周；10分=1-2个月；5分=>2个月 |

**评分计算示例**：

> 某光模块公司：Q2业绩预告在2周内发布（时间20分），市场普遍预计增长50%但实际可能达100%以上（弹性25分），已有5家分析师覆盖但分歧极大（认知度15分），业绩预告属于"大概率"事件（确定性25分）。
> 总分 = 25×0.3 + 25×0.3 + 15×0.2 + 20×0.2 = 7.5 + 7.5 + 3.0 + 4.0 = 22.0 ≈ **22分** ❌
>
> *等等——按满分100，得分=25+25+15+20=85×权重...让我重新算。*
>
> 确定性=25/30×30 = 25分；弹性=25/30×30 = 25分；认知度=15/20×20 = 15分；时间=20/20×20 = 20分；**总分 = 25+25+15+20 = 85分** ✅ 通过。

**快速打分法**：
1. 能否用一句话说清催化剂？（不能 → 直接淘汰）
2. 事件确定性打分：已公告30、大概率20、可能10
3. 弹性打分：估算净利润增量% × 1（上限30）
4. 认知度打分：20 - 已有覆盖家数 × 3（下限5）
5. 时间打分：2周内20、1月内15、2月内10、更远5

## 伪催化剂识别标准

以下特征出现任一项，直接判定为伪催化剂，淘汰：

| 伪催化剂特征 | 判定标准 | 举例 |
|:--|:--|:--|
| **概念模糊** | 无法指定具体产品或服务 | "涉足AI领域"、"布局新能源" |
| **无营收支撑** | 相关业务营收占比 < 5% | "子公司正在研发xxx"但无收入 |
| **无订单/产能** | 没有公开的订单公告或产能建设计划 | "已与某客户洽谈"但无签约 |
| **无时间路线图** | 无法说出催化剂何时落地 | "未来将..."、"计划..." |
| **管理层自说自话** | 仅来自互动平台/媒体采访，无正式公告 | CEO在互动平台自问自答夸大芯片进度 |
| **已被充分预期** | > 80%的分析师已在报告中定价该事件 | "利好出尽"型催化剂 |

**核心纪律**：催化剂必须可以写进"具体指标变动"（如"Q2营收预期从+15%上修至+30%"），否则不参与。
