## 核心原则

> **不在精确点位下单，而在"逻辑确认窗口"分批介入。**

事件驱动交易的收益来源是认知差，而非精确的日内择时。关键在于：
- 确认催化剂逻辑有效
- 在合理价位区间分批介入
- 永远留后手，不打满

## 首次建仓

### 基础仓位：可投资金的 40% – 50%

### 触发条件（需同时满足）

| # | 条件 | 验证方式 |
|:--|:--|:--|
| 1 | 标的已通过三重漏斗筛选 | 漏斗一主线 + 漏斗二评分 ≥ 70 + 漏斗三全绿灯 |
| 2 | 股价回踩至60日或120日均线附近并获得明确支撑 | 长下影线、阳包阴形态 |
| 3 | 催化剂事件进入倒计时 4–8 周窗口 | 有明确的时间节点公告 |

### 执行方式

1. 于支撑位当日或次日分 **2–3 笔**买入
2. 不打满计划仓位，留后手
3. 单日买入量不超过该标的近20日日均成交量的 5%（避免冲击成本）

### 买入价格区间参考

| 支撑参考 | 买入区间 |
|:--|:--|
| 60日均线支撑 | 均线价位 ± 1% |
| 120日均线支撑 | 均线价位 ± 1.5% |
| 前期整理平台上沿回踩 | 平台上沿 ± 1% |

### 买入执行建议

- 股价触及支撑位 → 第1笔（计划的25%）
- 次日确认支撑有效（未跌破支撑位且收阳）→ 第2笔（计划的15-25%）
- 避免在支撑位被跌破当日加仓（等待重新站回支撑位再考虑）

## 加仓信号

### 追加仓位：可投资金的 30%

### 触发条件（满足其一即可，且总持仓未超计划上限）

#### 加仓信号 A：催化剂先导信息公布

| 条件 | 细节 |
|:--|:--|
| 触发事件 | 业绩预告大幅上修、订单公告、政策细则出台等 |
| 价格条件 | 公告后股价高开 ≤ 5%，盘中回落至均线时 |
| 量能条件 | 无异常放量（当日量 < 50日均量的300%） |

> 若高开 > 7%，则放弃了。宁可错过，不可追高。

#### 加仓信号 B：技术突破确认

| 条件 | 细节 |
|:--|:--|
| 触发事件 | 股价带量突破前期整理平台上限 |
| 量能条件 | 当日成交量突破50日均量的 150% |
| 确认条件 | 突破后次日收盘未跌回平台内（假突破风险排除） |

#### 加仓信号 C：比价效应补涨

| 条件 | 细节 |
|:--|:--|
| 触发事件 | 同行业龙头率先联动大涨，形成板块效应 |
| 价格条件 | 该标的涨幅仍相对滞后（龙头涨15%+，该标的涨<5%） |
| 逻辑条件 | 基本面逻辑与龙头同向（非劣质补涨） |

## 严禁加仓的情况

以下任何情况出现，不得追加仓位：

| # | 情况 | 原因 |
|:--|:--|:--|
| 1 | 股价自首次建仓起累计涨幅已超 25% | 盈亏比已不划算，仅持有或考虑分批止盈 |
| 2 | 全市场跌停家数 > 15 家 | 大盘情绪退潮期，系统性风险高 |
| 3 | 催化剂事件出现延迟信号 | 任一节点延迟超2周，暂缓加仓 |
| 4 | 标的出现危险信号 | [monitoring-framework.md](monitoring-framework.md) 中任一危险信号出现 |
| 5 | 账户日亏损触及 2% | 当日停止所有新开仓（参见 risk-management.md） |
| 6 | 总持仓已达上限 | 单票 ≤ 50%，总持仓 ≤ 60%（或收益+20%后 ≤ 50%） |

## 仓位管理参数

以可投资总资金为 100% 参照。

### 单票限制

| 参数 | 值 | 说明 |
|:--|:--|:--|
| 单票计划上限 | 50% 可投资金 | 首次建仓（40-50%）+ 加仓（30%）= 上限 |
| 首次建仓 | 40-50% 可投资金 | 分批2-3笔执行 |
| 追加仓位 | 30% 可投资金 | 仅在加仓信号触发时 |

### 组合限制

| 参数 | 值 | 说明 |
|:--|:--|:--|
| 同时运行标的数 | ≤ 2 只 | 不同细分方向，防止单一事件风险集中 |
| 总持仓上限（初始） | ≤ 60% 可投资金 | 永远留 40% 现金应对极端或新机会 |
| 总持仓上限（收益+20%后） | ≤ 50% 可投资金 | 自动下调，锁利机制 |
| 总持仓上限（收益+50%后） | ≤ 30% 可投资金 | 进一步降低风险暴露 |

### 现金储备

永远保留 ≥ 40% 现金。现金的三大用途：
1. 遭遇极端行情时生存
2. 新催化剂机会出现时有资金参与
3. 已持标的出现加仓信号时有弹药

---

## 资金管理金字塔

```
收益 +50% ─── 总仓位上限 30% ─── 极度保守，大幅锁利
    ↑
收益 +20% ─── 总仓位上限 50% ─── 逐步锁利，降低风险
    ↑
初始阶段 ─── 总仓位上限 60% ─── 正常操作区间
    │        单票 ≤ 50%
    │        同时 ≤ 2 只
    │
    └────── 现金 ≥ 40% ─── 永远保留
```
