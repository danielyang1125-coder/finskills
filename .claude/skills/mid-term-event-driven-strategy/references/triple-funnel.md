# 三重漏斗筛选系统

中线事件驱动策略的选股过滤机制。三道漏斗依次递进，前一道不通过则直接淘汰。

## 漏斗总览

```
全市场候选 (~5000只)
    ↓ 漏斗一：主线板块确认
主线赛道标的 (~200-500只)
    ↓ 漏斗二：强催化剂筛选（评分 ≥ 70）
高催化剂候选 (5-15只)
    ↓ 漏斗三：技术面 + 基本面双确认
最终候选标的 (1-3只)
```

## 漏斗一：主线板块确认

### 规则

只交易当前市场公认的主线赛道。非主线板块的标的即使有催化剂也不参与。

### 每日复盘统计

| 统计维度 | 数据来源 | 阈值 |
|:--|:--|:--|
| 板块涨停家数占比 | 行情数据 | 板块涨停数 / 板块成分股数 > 5% |
| 板块成交额占比 | AKShare `stock_board_industry_spot_em()` | 持续 > 15% = 强主线；> 10% = 主线 |
| 产业全球共振 | 美股对应板块对比 | 美股同板块近1月走势是否同向且强于大盘 |
| 板块内轮动 | 龙头→二线→补涨的扩散 | 补涨出现时仍未结束 |

### 主线判定标准

| 强度 | 条件 |
|:--|:--|
| **强主线** | 成交占比 > 15% + 涨停数占比 > 5% + 美股共振向上 |
| **主线** | 成交占比 > 10% + 涨停数占比 > 3% |
| **潜在主线** | 成交占比在5-10%但呈上升趋势 + 政策/产业催化 |
| **非主线** | 成交占比 < 5%，无产业趋势 |

### 当前主线参考（截至2026年5月）

| 主线赛道 | 核心驱动 | 标志性事件 |
|:--|:--|:--|
| AI算力基础设施 | 全球AI军备竞赛，北美CSP资本开支持续上修 | 光通信、液冷、HBM业绩兑现期 |
| 商业航天 | 低轨卫星互联网建设加速 | 频段申请、发射计划密集公告 |
| 全球资源品（小金属） | 供给刚性+新能源需求拉动 | 锑、钨、稀土价格持续走强 |
| 人形机器人核心零部件 | 特斯拉Optimus量产渐进 | 丝杠、传感器、减速器国产替代 |

> **注意**：主线是动态变化的，随市场环境和产业进展而调整。以上仅为分析时的参考框架，实际操作前需重新验证。

## 漏斗二：强催化剂筛选

### 规则

对候选标的逐一回答5个必答题，全部通过后进行量化评分。评分 ≥ 70 进入漏斗三。

### 必答题（任一项不通过即淘汰）

1. **催化剂是什么？** — 必须用一句话说清，否则淘汰
2. **发生的时间窗口？** — 模糊的"未来"视为无催化剂，淘汰
3. **该信息目前是否已被市场广泛预期？** — 若 > 50% 分析师已覆盖，超额收益大打折扣，降分处理
4. **催化剂能否量化为业绩增量？** — 估算弹性空间，无法量化则降分
5. **消息是否来自正式公告？** — 仅传闻/互动平台/媒体采访而无正式公告 → 伪催化剂，淘汰

### 量化评分

使用 [catalyst-classification.md](catalyst-classification.md) 中的评分表四维度打分：
- 事件确定性（30%）
- 业绩弹性（30%）
- 市场认知度（20%）
- 时间临近度（20%）

**通过线：总分 ≥ 70**

## 漏斗三：技术面与基本面双重确认

### 技术面条件（需同时满足）

#### 流通市值

| 条件 | 标准 |
|:--|:--|
| 下限 | ≥ 30亿人民币（保证流动性） |
| 上限 | ≤ 100亿人民币（保证弹性） |

> 如果标的市值超出此范围但催化剂极强（评分 ≥ 85），可放宽至 20亿–200亿。

#### 月线位置

| 条件 | 标准 |
|:--|:--|
| 月线BOLL位置 | 中轨附近或刚从下轨回升（非高位） |
| 月线MACD | 零轴上金叉优先；零轴下金叉次之 |
| 月线RSI | **禁止**：月线RSI > 80（高位风险） |

#### 量价形态

| 条件 | 标准 |
|:--|:--|
| 成交量放大 | 近20个交易日日均成交量较前20日放大 > 30% |
| 底部倍量阳线 | 至少出现一次：单日涨幅 > 5% 且成交量为前日 > 2倍 |
| 无异常放量下跌 | 排除：单日跌幅 > 7% 且量为50日均量 > 200% |

#### 均线支撑

| 买入参考位 | 条件 |
|:--|:--|
| 60日均线 | 股价回踩至60日均线附近获得支撑（长下影线或阳包阴形态） |
| 120日均线 | 同上，但支撑力度弱于60日线 |
| 前期整理平台 | 平台上限被突破后回踩确认 |

### 基本面红绿灯

每项必须为 🟢 绿灯，任何一项为 🔴 红灯则淘汰。

| 检查项 | 🟢 通过 | 🔴 淘汰 |
|:--|:--|:--|
| ST/退市风险 | 无任何ST标识，无退市风险警示 | 有ST/\*ST标识或退市风险提示 |
| 审计意见 | 近两年审计意见均为标准无保留 | 任一年为非标意见 |
| 商誉占比 | 商誉/净资产 ≤ 30% | 商誉/净资产 > 30% |
| 大股东减持 | 近3个月无减持计划公告 | 近3个月有减持计划公告或正在减持 |
| 股权质押 | 大股东质押比例 < 50% | 大股东质押比例 ≥ 50% |
| 立案调查 | 无证监会立案调查 | 正在被立案调查 |
| 财务造假嫌疑 | 无公开质疑或监管问询 | 有监管问询函涉及财务问题未回复 |
| 流动性 | 日均成交额 ≥ 5000万元 | 日均成交额 < 5000万元 |

### 数据获取方式

调用 **金融数据工具包** (`findata-toolkit-cn`)：

```bash
# 技术面数据
python scripts/stock_data.py <代码> --history

# 基本面数据
python scripts/stock_data.py <代码> --metrics
python scripts/stock_data.py <代码> --financials
python scripts/stock_data.py <代码> --insider
```

计算指标时注意：
- 月线/周线/日线需从日线OHLCV数据聚合
- BOLL中轨 = MA20，上下轨 = MA20 ± 2×标准差
- MACD = EMA12 - EMA26，信号线 = MACD的EMA9
- RSI = 100 - 100/(1 + 平均涨幅/平均跌幅)，周期14

## 完整筛选流程清单

执行筛选时按此清单逐项检查，避免遗漏：

### 漏斗一
- [ ] 统计各板块成交额占比
- [ ] 统计各板块涨停家数占比
- [ ] 检查美股对应板块走势（全球共振）
- [ ] 确认当前主线赛道列表（≤ 5个）
- [ ] 将候选标的限定在主线赛道内

### 漏斗二
- [ ] 对每个候选标的用一句话描述催化剂
- [ ] 确认催化剂时间窗口（具体到周）
- [ ] 评估市场认知度（分析师覆盖数）
- [ ] 量化业绩弹性空间
- [ ] 四维度评分
- [ ] 筛选总分 ≥ 70 的标的

### 漏斗三
- [ ] 检查流通市值范围
- [ ] 计算月线BOLL/MACD/RSI
- [ ] 检查量价形态（量能放大、倍量阳线）
- [ ] 确认均线支撑位
- [ ] 基本面红绿灯全项检查
- [ ] 输出最终候选标的
